## Plan vs. Implementation

5. Which part of the work took more or less time than expected? Why?

Answer: The part that took more time than expected was configuring and testing the API documentation with Swagger. 
I had to make sure all routes were properly documented, generate the Swagger JSON file, 
and verify that everything worked correctly both locally and on Render. 
The implementation of the API routes was easier because I followed the same patterns for models, 
controllers, and routes.

6. How did Swagger help you in your work this week?

Answer: Swagger helped me test and validate all API routes in one place. 
It made it easier to send requests, check response codes, and verify that the API behaved as expected. 
It also helped me create clear and organized documentation for the Books and Authors APIs.
