6.b. What decision does this file show, and why did you make that choice?

Answer:
This file shows my decision to handle different outcomes by returning appropriate HTTP status
codes and JSON responses.
I chose this approach to make the API easier to use and understand. 
The controller returns status code 200 when a book is found, 404 when a book is not found,
and 500 for unexpected errors. This helps clients understand the result of each request 
and provides safe error messages.
